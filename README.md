## 🏗️ Frequently Asked Questions

### Does this software use much battery?
The software monitors your hardware. When it detects that you use a laptop on battery power, it lowers the rendering speed automatically to protect your battery life.

### Can I use my own images?
Yes, you can import images or video files into the application to create custom animated scenes. The software handles basic animation layering for you.

### What happens if my wallpaper stops moving?
Check the "Playback" section in the settings. Ensure that the app is not set to pause when other windows are active. If the issue persists, restart the application from the tray menu.

### How do I update to the latest version?
The application checks for updates when you start it. You can also manually trigger an update by selecting "Check for Updates" in the system tray menu.

## 🛡️ Troubleshooting Common Issues

*   **Black Screen:** This usually happens when the graphics card driver is out of date. Update your display drivers via your manufacturer's website.
*   **High CPU Usage:** Lower the resolution scale in the settings menu. This makes the background render at a lower resolution while keeping the desktop clear.
*   **Background Disappears:** Ensure the application is set to launch at startup. You can find this option under the "General" tab in the settings window.
