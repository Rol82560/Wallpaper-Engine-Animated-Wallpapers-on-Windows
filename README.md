# Wallpaper Engine

> **Wallpaper Engine** — Powerful tool to create and use beautiful animated wallpapers on your Windows desktop.

## ❗️ Troubleshooting
| Problem                    | Solution                                      |
|----------------------------|-----------------------------------------------|
| App doesn't start          | Run as Administrator                          |
| Low FPS on desktop         | Lower wallpaper quality or disable heavy effects |
| Black screen               | Restart explorer or switch wallpaper mode     |
| Antivirus warning          | Add the folder to exclusions                  |
| Performance issues         | Close background programs or reduce settings  |
